# Boom Art！

DeepSeek Harness 的桌面端与 Web 端通用插件。每次发送消息时，把当前输入框当作**唯一的爆心**，只向输入框边界**外侧**径向绽放：

- 输入框内部完全不放任何特效，只保留输入框原本的内容。
- 边界保留一圈清晰的 LED 式描边，整体渐亮再渐灭，不再绕边界跑动。
- 以输入框中心为圆心，向上下左右和四个斜角同时向外炸开，是一个环绕输入框的大烟花，而不是许多小烟花拼在一起。
- 每次迸发多个随机 emoji。
- 每次迸发多个**相同**的随机夸夸文字（从“太厉害了！”“牛逼！”“我勒个豆！”“完美的指令！”“完美无瑕！”中选一句）。
- 细线火花带拖尾；不使用模糊泛光，只有清楚的边缘亮线与描边。
- 输入框工具栏里有一个小型烟花设置按钮。

## 安装

这是一个 DSH 的本地 bundle，不是独立网页，也不是普通的 npm 前端包。

1. 将本仓库放到本机任意目录。
2. 在 DSH 的插件管理入口选择“从本地目录安装 bundle”，目标选本仓库根目录。
   - 如果通过 DSH 内的 agent 安装，等价于调用 `plugin_manager` 的 `install_bundle`，`target` 填本仓库的绝对路径。
3. 安装完成后重载 DSH。输入框工具栏会出现烟花按钮。

卸载：在插件管理器中移除 `@local/boom-art`。

## 隐私

- 不发起网络请求，不包含统计、遥测、远程字体或远程图片。
- 不读取、保存或上传聊天记录。发送检测只在本机内存中判断当前草稿是否为空、附件数量是否变化，不分析、不记录草稿文字。
- 仅向本机 `localStorage` 写入两项设置：是否开启、当前强度；不包含任何个人信息。
- 图标、颜色和字体全部随插件本地提供。

## 设置

- **特效强度**：1–5 级 + 特殊 `MAX` 级。强度同时改变三件事：
  - 烟花向外飞出的**长度**
  - 火花的**拖尾长度**
  - 火花、emoji、文字的**密集数量**
- `MAX` 会以超长拖尾和极高密度糊满输入框外侧，故意追求“卡卡的糊脸感”，可能明显掉帧；1–5 级按正常播放调校。
- **特效开关**：关闭时先弹出确认；确认后显示“（倒地不起）”并在一秒后关闭。再次打开会立即按当前强度播放一次，并显示“（瞬间原地复活）你果然回来了！🥳”。
- **试放当前强度**：不发送消息也能预览。
